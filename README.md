# 🐽 6657 串子生成器

斗鱼 6657 直播间（玩机器 CS）串子风格弹幕生成器：输入一条弹幕，AI 从 23701 条站内烂梗库中检索贴合的梗，一次给出 3 条候选串子回复，你点选最串的一条。

## 玩法

1. 输入一条弹幕（例：`玩机器提及选手 niko`）
2. 拖浓度滑块（1 点到为止 / 2 正常浓度 / 3 火力全开）
3. 等 10~30 秒出 3 张候选卡片，点"就用这条"；都尬就点"都不行 👎"

每天共 300 次生成额度（所有玩家共享），用完明天再来 🐷

## 数据来源声明

烂梗数据来自 sb6657.cn（水友共同创作、站长整理维护），本项目仅作检索引用，不主张对数据本身的任何权利。

## 技术说明

- Streamlit + DeepSeek（deepseek-chat）
- 流水线：语境判断（t=0.0）→ 池内二段检索（外号词典 + 场景词 + bigram 相关性）→ 并行生成 3 条候选（t=0.9，各绑定不同主梗）
- 部署在 Streamlit Community Cloud，见 DEPLOY.md

仅供粉丝群内娱乐交流。
